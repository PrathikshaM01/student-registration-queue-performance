# Student Registration Queue Performance Modeling

## Project Description

This mini project focuses on the performance modeling and evaluation
of a student registration queue during a university registration
process.

The study evaluates the effect of different numbers of registration
officers on system performance.

## Performance Objectives

The project evaluates:

1. Average student waiting time
2. Queue length
3. Registration officer utilization
4. System throughput
5. Performance comparison between different numbers of officers

## Dataset

The dataset contains simulated student arrival times and registration
service times.

## System Configurations

The model will compare:

- 1 registration officer
- 2 registration officers
- 3 registration officers
- 4 registration officers
